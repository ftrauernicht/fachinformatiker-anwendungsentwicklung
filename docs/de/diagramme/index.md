# Diagramme

Notationen, die in der Abschlussprüfung gezeichnet oder gelesen werden müssen.

Die ersten beiden bilden dabei eine Ausnahme: Programmablaufplan und Struktogramm sind mit dem [Prüfungskatalog von 2025](../00-pruefung.md) aus der Prüfung herausgefallen. Sie stehen hier weiter, weil sie im Berufsschulunterricht vorkommen — als Prüfungsantwort taugen sie nicht mehr. Erwartet werden stattdessen Pseudocode und das Aktivitätsdiagramm.

| Diagramm | Zweck | Typische Prüfungsaufgabe |
|---|---|---|
| [Programmablaufplan (PAP)](01-programmablaufplan.md) | Ablauf eines Algorithmus, DIN 66001 | seit 2025 nicht mehr geprüft |
| [Struktogramm](02-struktogramm.md) | Ablauf ohne Sprünge, DIN 66261 | seit 2025 nicht mehr geprüft |
| [Klassendiagramm](03-klassendiagramm.md) | Statischer Aufbau eines OO-Systems | Klassen und Beziehungen aus Text ableiten |
| [Anwendungsfalldiagramm](04-anwendungsfalldiagramm.md) | Systemgrenze und Akteure | Use Cases aus Anforderungstext ableiten |
| [Entity-Relationship-Modell](05-entity-relationship-modell.md) | Datenmodell vor der Normalisierung | ERM zeichnen, Kardinalitäten bestimmen |
| [Zustandsdiagramm](06-zustandsdiagramm.md) | Lebenszyklus eines Objekts | Zustände und Übergänge aus einem Ablauftext ableiten |
| [Aktivitätsdiagramm](07-aktivitaetsdiagramm.md) | Ablauf mit Nebenläufigkeit und Zuständigkeiten | Kontrollstruktur oder Geschäftsprozess zeichnen |
| [Sequenzdiagramm](08-sequenzdiagramm.md) | zeitliche Abfolge von Nachrichten | Anwendungsfall als Nachrichtenfolge darstellen |
| [Objektdiagramm](09-objektdiagramm.md) | Momentaufnahme konkreter Objekte | prüfen, ob es zum Klassendiagramm passt |
